Macropad
a custom macropad with 4 switches, a rotary encoder, and an OLED display that is supposed to be interactive. 

Status
- Schematic and PCB layout: complete (KiCad)
- Case design: complete (Fusion 360, exported as STEP)
- Firmware: complete and compiles successfully (QMK, RP2040)
- Physical assembly: pending parts/funding

  Files
- `Macropad_v1.kicad_sch` / `.kicad_pcb` / `.kicad_pro` — schematic and PCB design
- `Macropad v2.step` — 3D case model
- `keyboard.json`, `rules.mk`, `keymap.c` — QMK firmware
